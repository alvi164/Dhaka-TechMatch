# 🎯 Dhaka TechMatch: Localized Job Skill Matcher

Dhaka TechMatch is an AI-powered skill-gap analyzer designed explicitly to bridge the gap between academic theory taught in universities and the rapid, stack-specific requirements of Bangladesh's modern tech ecosystem.

## 💡 The Problem
Many university grads in Dhaka possess strong theoretical foundations but lack the specific stack experience (e.g., Spring Boot, NestJS, Flutter, or localized cloud infra patterns) actively sought out by top local employers on platforms like Bdjobs and LinkedIn.

## 🚀 Key Features
- **Contextual Local Analysis**: Tailors skill assessments based on the exact type of enterprise in Bangladesh (Fintech, Ride-Sharing, or Software Houses).
- **Automated Resume Benchmarking**: Uses the `OpenAI API (gpt-4o-mini)` to perform a fast semantic audit of pasteable resume profiles.
- **Custom 3-Month Action Roadmap**: Generates a hyper-focused learning plan designed to make the applicant highly hireable within 90 days.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **AI Core**: OpenAI Developer Platform API
- **Environment Management**: Python-Dotenv
